## 학습과 평가 조건

- 학습은 시드 `11`, `BP_SHArena` 10개, 에이전트 200개, 셀프플레이, 조준 보조 끔으로 진행했다. 팀 평균 보상 혼합 비율은 `0.30`, 라운드 결과 보상은 `2`였다.
- 기준군은 57,844,800스텝에서 네트워크와 보상 카운터를 복원하고 옵티마이저를 다시 초기화한 뒤 목표 스텝까지 학습했다. 변형 6개는 처음부터 학습했다.
- 평가는 각 변형이 `Base75M`과 400경기씩 맞붙는 방식으로 총 2,400경기를 진행했다. 초기 배치 50개, 정책 난수 2회, 시작 진영 2개, 팀 역할 2개를 교차했다. 시뮬레이션은 고정 60Hz, 행동 잡음은 `1.0`, 조준 보조는 껐다.
- 승점률은 `(승 + 0.5 × 무승부) / 전체 경기`다. 시간초과와 동시 전멸은 무승부로 집계했다. 초기 배치 단위 부트스트랩과 6개 대진 Bonferroni 보정을 적용했다.

사망 벌점 두 변형과 처치 보너스 +50%가 기준군 상대 향상 기준을 충족했다. 사망 벌점 두 변형의 관측 승점률 차이는 1.25%p였으며, 배치 단위 탐색적 95% 구간은 −5.1~+7.6%p였다. 이 결과의 범위는 단일 학습 시드에서 저장한 체크포인트 간 성능이다. 기준군과 변형의 학습 재개 이력 차이도 해석에 고려해야 한다.

## 스냅샷 사용

모델을 선택할 때는 표에 있는 `cum…` 폴더를 지정한다. 각 폴더는 관측 크기 `176`을 기록하며, 정책 실행에 사용하는 `policy.bin`, `encoder.bin`, `decoder.bin`과 `critic.bin`, `meta.txt`, `experiment.json`을 저장한다. 실제 파일명에는 스냅샷 폴더 이름이 접두사로 붙는다. 폴더 이름의 시간은 누적 학습 시간을 표시하며 상호 비교의 기준은 `total_reward_steps`다.

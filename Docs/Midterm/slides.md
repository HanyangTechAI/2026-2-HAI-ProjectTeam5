## 2. 무엇을 만들었나 (한 장 요약)

- 유닛 하나하나가 **조준 · 이동 · 사격**을 스스로 결정하는 신경망 정책
- 이 정책을 학습시키는 환경: 팔각형 아레나에서 **10 대 10 라운드**를 16판 동시에 진행
- 같은 정책끼리 싸우며 배운다 (**self-play**) — 사람이 만든 정답 행동이나 녹화 데이터 없음
- 지금까지 누적 16시간 학습

**대본**: 사람이 행동을 짜 주는 대신, 유닛이 매 0.05초마다 보이는 정보를 보고 회전·이동·발사를 고른다.
좋은 결과가 나온 선택을 더 자주 하도록 반복해서 고친다.

## 3. 전체 구조 — `figures/01_architecture.png`

- 언리얼 엔진이 게임을 돌리고, 학습(PPO)은 별도 파이썬 프로세스가 GPU 로 한다
- 아레나 16개 × 유닛 20명 = 에이전트 320, 모두 **신경망 하나를 공유**
- 언리얼 → 파이썬: 경험(관측 · 행동 · 보상) / 파이썬 → 언리얼: 갱신된 가중치

**대본**: 왼쪽 큰 상자가 언리얼 안이다. 유닛이 관측을 만들고, 신경망이 행동을 고르고, 행동이 다시 게임에 반영된다.
그 기록이 쌓이면 오른쪽 파이썬 학습기가 신경망을 고쳐서 돌려보낸다.

## 4. 아레나와 라운드 규칙 — `figures/02_arena.png`

- 반경 17.5 m 팔각형, 엄폐물 7개, 양쪽 호 모양으로 10명씩 스폰
- 라운드 = 한 팀 전멸 또는 **45초**
- 시간 초과는 **양쪽 모두 패배** (TFT 와 같은 규칙)
- **축소 구역**: 20초부터 15초 동안 안전 반경 17.5 m → 6 m, 밖은 초당 HP 10% 피해
- 학습 중에는 라운드마다 두 팀 진영을 맞바꾼다

**대본**: 같은 실력끼리 싸우면 서로 엄폐물 뒤에서 버티기만 하는 교착이 생길 수 있다.
시간 초과를 양쪽 패배로 두고 안전 구역을 좁혀서 결국 싸우게 만들었다. 실제로 시간 초과 비율은 0% 근처다.

## 5. 유닛이 보는 것과 하는 것 — `figures/03_agent_io.png`

- **관측** (숫자 176개):
  - 시야 레이 16개 (90°): 벽 · 엄폐물 · 적 · 아군까지 거리
  - 보이는 적 최대 10명, 아군 최대 9명 (방향 · 거리 · HP)
  - 마지막으로 본 적의 방향, 마지막으로 맞은 방향
  - 팀 생존 비율 · 라운드 경과 · 안전 구역, 자신의 HP · 발사 가능 여부
- **행동** (0.05초마다): 회전 7단계 · 이동 5가지 · 발사 예/아니오
- 핵심 설계: **시야 레이와 총알이 같은 충돌 판정**을 쓴다 → "보인다" = "쏘면 맞는다"

**대본**: 적 좌표를 그냥 주지 않고 자기 시야로 본 것만 준다. 엄폐물 뒤의 적은 안 보이고, 그래서 엄폐가 의미를 가진다.

## 6. 보상 — 무엇을 잘했다고 알려 주는가 (표: `data/02_reward_terms.csv`)

| 항 | 값 |
|---|---|
| 준 피해 | +1.0 / 피해 100 |
| 받은 피해 | −1.0 / 피해 100 |
| 킬 / 사망 | +0.5 / −0.5 |
| 빗맞힘 | −0.005 / 발 |
| 생존 중 시간 | −0.002 / 결정 |
| 적을 시야에 둠 · 조준 정렬 | 소량, 학습 초반에만 크고 점점 줄어듦 |
| 팀 스피릿 | 받는 보상 = 0.7 × 내 보상 + 0.3 × 같은 팀 평균 |

- 준 피해와 받은 피해, 킬과 사망을 **같은 크기**로 맞췄다 (한쪽이 크면 겁을 먹거나 무모해진다)
- 죽은 유닛도 라운드 끝까지 팀 보상을 받는다 → 팀을 위한 희생을 배울 수 있다

**대본**: 빗맞힘 벌점을 0.05 로 크게 줬을 때는 쏘는 것 자체가 손해가 돼서 유닛이 사격을 거의 멈췄다.
그래서 아주 작게 남겼다.

## 7. 학습이 돌아가는 방식 — `figures/04_training_loop.png`

- 0.05초마다: 관측 → 행동 선택 → 실행 → 보상 → 기록
- 기록이 65,536개 쌓이면 PPO 로 신경망 갱신 (한 번에 수 초)
- 두 팀이 같은 신경망 → 상대도 함께 강해진다 (self-play)
- 1시간마다 신경망 저장 (`Snapshots/<날짜>/cum<누적 시간>/`) → 저장한 것에서 이어서 학습, 과거 버전과 대결로 평가
- 시각화 전용 레벨(`Lvl_SHView`)에서 학습된 정책을 실제 속도로 볼 수 있다

**대본**: 학습은 화면 없이 최고 속도로 돌리고, 확인할 때만 저장된 신경망을 시각화 레벨에 불러 본다.

## 8. 실제로 동작하는가 — `figures/05_winrate_vs_bot.png` (+ 시연 영상)

- 사람이 규칙으로 짠 **스크립트 봇**과 대결 (봇과는 한 번도 학습하지 않았다)
- 학습 1시간 20분에 처음 이기기 시작 → 누적 16시간 **97.5%**
- 과거의 자기 자신(11시간 정책)도 87% 이긴다 → 계속 강해지고 있다

**대본**: 그래프 왼쪽 음영 부분은 나중에 고친 버그가 있던 때의 측정이다. 고친 뒤 다시 재도 비슷했다(4시간 기준 79 → 80%).

**시연 영상 (팀이 직접 촬영)**: 에디터에서 `Content/RL/Lvl_SHView` 를 열고 Play.
파랑(팀 0) · 빨강(팀 1)으로 색이 칠해지고, 시야 레이가 그려진다. 10~20초 정도 녹화하면 충분하다.

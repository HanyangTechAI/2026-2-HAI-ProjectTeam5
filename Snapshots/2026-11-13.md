# 2026-11-13 학습 기록

## 수정사항

학습을 돌리지 않았다. 자동 학습 프로그램(`Training/train.py`)을 위해 트레이너에 실행 옵션 하나를 추가했다. 학습 동작은 바뀌지 않는다.

- `ASH_CombatTrainer`: `-SHSnapshotFlat=1` 이면 스냅샷을 날짜 폴더 없이 `<SnapshotRoot>/cum012h00m/` 에 저장한다.
  기본값은 꺼짐이라 기존 경로(`<SnapshotRoot>/<날짜>/cum012h00m/`)는 그대로다. 날짜별 기록 파일(`<SnapshotRoot>/<날짜>.md`)도 그대로 남는다.
- 이후 자동 학습은 `Training/<학습 이름>/` 아래에 쌓인다(`Training/README.md`).
- `ASH_CombatTrainer`: `-SHTrainSeconds=0` 을 명시하면 "제한 없음" 으로 덮어쓴다(전에는 0 을 무시했다).
  `Lvl_SHTrain` 의 트레이너 액터에 시험용 한도 300초가 남아 있어서, 명령줄로 끌 방법이 없었다
  (`Training/START_11_13` 첫 실행이 5분 만에 끝난 원인). `Training/train.py` 는 이제 항상 `-SHTrainSeconds` 를 넘긴다(시간 제한 없으면 0).
  레벨의 300초 값 자체는 그대로다 — 손으로 실행할 때 `-SHTrainSeconds` 를 주지 않으면 여전히 5분에 끝난다.

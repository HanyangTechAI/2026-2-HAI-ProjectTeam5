# 2026-11-16 학습 기록

## 수정사항

학습을 돌리지 않았다. 인게임에서 RL 모델(스냅샷)을 고르는 기능을 위해 학습 쪽 공용 파일에 함수만 추가했다. 학습 동작은 바뀌지 않는다.

- `RL/SH_SnapshotFiles`: `SHSnapshot::ReadMeta`(meta.txt → key=value 맵), `SHSnapshot::HasPolicyFiles`(policy · encoder · decoder 존재 확인) 추가.
  트레이너는 이 함수들을 쓰지 않는다(인게임 `ASH_BattleBrain` · 모델 목록 `SHPolicyCatalog` 만 쓴다).
- 인게임 정책 실행기는 이제 스냅샷 meta 의 `obs_size` 가 지금 코드의 관측 크기와 다르면 전투를 시작하지 않는다
  (전에는 엔진이 "Invalid Format" 만 찍고 정책이 무작위로 남았다).

- `ASH_CombatTrainer`: `-SHOpponentPoolOnly=1` 추가. 켜면 상대 풀에 `-SHOpponentPool` 폴더만 넣고 이번 실행의 스냅샷은 넣지 않는다.
  기본값은 꺼짐이라 기존 상대 혼합 동작은 그대로다. `Training/train.py` 의 "학습 상대 = 고정 모델" 이 이걸 쓴다
  (`-SHOpponentMix=1 -SHMixSnapshot=999 -SHMixBot=0 -SHOpponentPool=<스냅샷> -SHOpponentPoolOnly=1` → 모든 아레나가 그 모델과 싸운다).
  실행 기록 머리말의 "상대 혼합" 줄에 풀 폴더와 이 옵션이 같이 찍힌다.
- `Training/train.py`: 학습 상대(self-play / 스크립트 봇 / 고정 모델 / 혼합)를 고르는 메뉴. 이어서 학습할 때도 바꿀 수 있고 `run.json` 에 기록된다.

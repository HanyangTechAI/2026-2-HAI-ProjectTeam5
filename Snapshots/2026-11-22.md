# 2026-11-22 학습 기록

## 수정사항

학습을 돌리지 않았다. 학습 상대에 행동 트리를 더하고, 조준 · 명중 관련 스위치를 학습 실행기에서 고를 수 있게 했다.
**기본 설정(`-SHBotKind` 없음 = 스크립트 봇, 조준 스위치 기본값)으로 돌리는 학습의 동작은 바뀌지 않아야 한다.**

- `ASH_CombatTrainer`: `-SHBotKind=bt|script`(기본 script), `-SHBotTree=<에셋 경로>`(기본 `/Game/Battle/AI/BT_SHCombat`) 추가.
  - bt 면 조립 때 봇 아레나(`-SHSelfPlay=0` 의 전 아레나, 또는 혼합의 `-SHMixBot=M` 아레나)의 팀 1 컨트롤러를 스크립트 봇에서
    `ASH_BTBotController` 로 바꾸고 트리를 시작한다. 새 라운드마다 트리를 멈췄다가 처음부터 다시 돌린다(사망 시 멈춘 트리 재개. 블랙보드 값 자체를 지우는 것이 아니라 Perceive 서비스가 시작될 때 적을 본 기억을 지운다).
  - 트리를 못 불러오면 Error "-SHBotKind=bt 를 적용하지 못해 종료한다" 를 찍고 끝낸다(train.py 가 그 문구를 보고 재시작하지 않는다).
  - ★ `CollectAgentUnits` 에서 행동 트리 컨트롤러를 뺐다. `ASH_BTBotController` 가 `ASH_RLBotController` 를 상속해서,
    빼지 않으면 상대 정책(OpponentManager)의 에이전트로 등록되어 트리와 정책이 같은 유닛을 동시에 움직였을 것이다.
  - 실행 기록 머리말의 "- 맵:" 줄에 "봇 아레나 상대 = 스크립트 봇 / 행동 트리 `BT_SHCombat`" 를 붙였다. 아레나 역할 로그도 봇 종류를 찍는다.
- `Training/train.py`:
  - 학습 상대 "행동 트리"(`-SHSelfPlay=0 -SHBotKind=bt`), 혼합 상대의 봇 종류(`bot_kind`). 스크립트 봇은 이제 `-SHBotKind=script` 를 명시한다.
  - 조준 · 명중 설정 — 조준 보조(`-SHAimAssist`, 강도), 정렬 보상(`-SHAimReward`, 배율), 시야 보상(`-SHSeeReward`, 배율)을 켜고 끈다.
    `run.json` 의 `"aim"`, 바꾸면 `"aim_history"`. 실행기가 여섯 옵션을 항상 명시한다. 기본값은 트레이너 기본값(보조 끔, 정렬 · 시야 켬 x1)과 같다.
  - 확인: "명중률 기준으로 보상을 잠그는" 장치는 코드에 없다. 명중 1발당 보너스(`HitBonus` 0.1)는 원격 브랜치 `yongjin-hit-bonus` 에만 있다(미병합).
